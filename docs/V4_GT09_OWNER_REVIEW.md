## 사용법

1. 사례를 선택하고 원본을 확인한다. 처음에는 모든 픽셀이 **미검토**다. 필요하면 **직접 선택: 전체 UNKNOWN**을 누르고 페이지 확인창에서 적용한다. 이것은 수동 불확실성 선언이지 텍스트를 확인했다는 뜻이 아니다.
2. TEXT(빨강), NON_TEXT(파랑), MIXED(보라), UNKNOWN(노랑)을 고른 뒤 브러시·사각형·다각형으로 직접 표시한다. 다각형은 꼭짓점을 클릭하고 **다각형 적용**을 누른다. 취소는 현재 다각형 선택만 버린다. 적용 전 다각형이 있으면 저장·사례/도구 전환·확정을 막아 선택을 잃지 않게 한다. 사각형과 다각형은 선택 영역을 사람이 지정하는 도구이며 이미지 내용은 분석하지 않는다.
3. 확대 슬라이더(50–800%), **원본 100%**, 이동 도구 또는 Space+드래그로 이동한다. 기본 화면은 원본 100%이며 확대는 표시 크기만 바꾼다. 주석 투명도를 조절하거나 **주석 보기**를 해제하면 원본을 가리지 않고 확인할 수 있다. 실행 취소/다시 실행 또는 Ctrl/⌘+Z, Ctrl/⌘+Shift+Z를 사용할 수 있다.
4. **저장 / 이어하기**로 디스크에 저장한다. 다음 실행에도 같은 `--out` 경로를 쓰면 복원된다. 사례 변경 시 현재 작업이 먼저 저장된다. 브라우저를 닫기 전에 저장해야 한다. 서로 다른 탭의 오래된 저장은 덮어쓰지 않고 거부한다.
5. 커버리지에서 UNKNOWN·MIXED·미검토 수량과 비율을 확인하고 체크박스를 선택한 뒤 **현재 사례 검토 확정**을 누른다. 미검토가 있으면 확정할 수 없다. UNKNOWN/MIXED는 확정 뒤에도 그대로 남으며, 확인창에도 실제 수량이 표시된다. 확정은 관찰의 정확성 보증이 아니다. 편집하면 다시 미확정이 된다.
6. 다섯 사례를 모두 확정한 뒤 **5개 확정본 RLE 내보내기**를 누른다. 브라우저가 `gt09-owner-review.json`을 내려받고, 서버도 동일 바이트를 해시 이름으로 보존한다. JSON을 직접 편집할 필요가 없다.

NON_TEXT는 배경이나 음악 등 ‘텍스트 아님’이라는 소유자의 관찰이다. 음악 제거 권한이 아니다. MIXED는 분리하기 어려운 공유 내용, UNKNOWN은 판단하지 못하거나 작업하지 않은 내용으로 사용할 수 있다. 전부 UNKNOWN으로 확정한 사례도 그 커버리지를 명시하며 정확도·완료된 분류로 해석하지 않는다.

## 저장·내보내기 계약

- 임시 작업: `gt09-output/owner-state.json`. 저장은 임시 파일 작성 및 원자적 교체로 처리한다. 이 파일은 수정 가능한 작업 상태이며 독립 리뷰의 불변 원본이나 서명 제출물이 아니다.
- 최종 내보내기: `gt09-output/owner-review-exports/<SHA-256>.json`. 동일 주석은 저장 횟수와 무관하게 동일 바이트/해시로 내보낸다. 기존 내보내기는 덮어쓰지 않는다.
- `review_type=OWNER_REVIEW`, `evidence_status=NOT_INDEPENDENT_GROUND_TRUTH`, 정확한 패킷/사례/이미지 해시, 원본 크기, 좌표 규약 및 수동 확정/불확실성 확인 상태를 기록한다. 인간 신원·독립성 서명·증명서를 만들지 않는다.
- 좌표는 crop-local 정수 pixel-index center: 첫 중심 `(0,0)`, x는 오른쪽, y는 아래. RLE는 `[y,left,right_exclusive,label]`. 행마다 왼쪽부터 모든 픽셀을 한 번씩 기록하며 같은 범주의 인접 run은 합친다.
- 저장 중 미검토는 명시적 `UNREVIEWED`로 보존한다. 최종 내보내기에는 TEXT/NON_TEXT/MIXED/UNKNOWN만 허용한다. 누락·중복·범위 초과·비정수·해시/크기/사례 불일치 및 미확정 사례를 거부한다.
- 원본과 주석은 별도 캔버스다. 수동 도형은 정수 중심을 포함하는 픽셀에만 라벨을 기록하며 선택 경계는 포함한다. 브러시 반경은 원본 픽셀 단위의 원형, 0–40 px로 제한한다. 포인터 보간은 사람이 그린 선만 연결하며 원본 픽셀 값은 읽어 분류하지 않는다.
- 실행 취소/다시 실행은 현재 사례의 최근 50회까지 메모리에서만 유지한다. 저장된 주석은 재개되지만 과거 undo 이력은 재개되지 않는다.

네트워크는 로컬 파일/서버 요청만 사용한다. OCR·분할·임계값·AI 분류·외부 CDN·계정은 없다. 변경 요청은 로컬 Host/Origin 및 세션 토큰으로 제한한다. 여러 독립 서버가 같은 저장 디렉터리를 동시에 사용하는 방식은 지원하지 않는다. 한 서버를 사용한다.
