# Independent source-reading workflow pilot

This is a workflow rehearsal using an existing image packet. It establishes neither whole-score accuracy nor an accepted reference denominator. No answers, predictions or desired error findings are supplied.

## Materials and access

The custodian supplies only the unchanged GT-02 `independent-reference-packet/`, the neutral `reader-schedule.json`, and a separate writable copy of the original full `blank-A.json` or `blank-B.json`. The schedule binds `cases.json` by SHA-256. Keep all 111 cases and original image bytes; work the 14 priority IDs first. Do not create new crops, renumber cases, remove other cases or edit the distributed packet. Page and system context remain available for uncertainty about boundaries.

Never distribute coordinator/private indices, research reports, recognition results, predictions, error hypotheses, the repository, or the parent diagnostic directory. The pilot schedule is deliberately curated for workflow coverage, not randomly sampled for accuracy estimation. Readers should not be told selection rationales or asked to find a particular error.

## Eligibility and separate sessions

Two music-literate readers A and B must be independent of the GT-01/GT-02/GT-03 coordinator, recognition and architecture work, and must not have seen candidate answers or the other's observations. A separate eligible adjudicator must be distinct from both readers and the coordinator. The custodian verifies actual identities, expertise and exclusions externally; JSON cannot authenticate people.

Before viewing cases, freeze an eligibility record for each person: identity, assigned role, expertise, prior exposure, involvement exclusions, training-page hashes and evaluation-page exclusions, timestamp/timezone and attestation. Do not use any of the evaluation pages for training. A breach is recorded and collection paused; it is not silently erased by signing another form.

A and B use separately controlled sessions and storage. Neither sees the other's progress or export. Read each version from its physical ink; do not copy or mentally transpose another version into an answer. Record notes/rests, timing, voices, spelling, chord literal text/qualities/alterations/slash basses, ties/slurs, endings and uncertainty using the unchanged packet instructions. UNKNOWN, PARTIAL and UNREADABLE are valid observations. Null means unknown; an empty list means explicitly observed none. Leave every unworked case PENDING.

## Preserve and freeze observations

Keep each received export byte-for-byte, including uncertain answers and PENDING cases. Never replace the original with a cleaned or adjudicated version. Store exports outside the read-only packet in separate A/B locations; use create-only file creation and independently controlled read-only retention. Hash raw bytes with SHA-256 and retain a receipt recording packet cases hash, export hash, role/person, acquisition and freeze time/timezone, eligibility-record hash and exposure log. Keep a second receipt in a separately controlled location. Ordinary local read-only files alone are not immutable custody or trusted timestamps.

Compare nothing until **both pilot exports are frozen**. A pilot export containing PENDING cases cannot pass the GT-02 full 111-case submission validator and must not be submitted as a completed reference. Record it only as a pilot workflow receipt. For later full collection, start new working drafts continuing all 111 IDs; preserve pilot exports and their receipts. Freeze final A/B exports separately and validate their complete schema with the existing GT-02 validator. A schema pass is not acceptance as musical truth.

## Disagreements and adjudication

Only after both freezes may the separate adjudicator receive native images and the two frozen observations, never coordinator answers or algorithm results. Record case/field disagreements, both literal originals, the adjudicator's observation, uncertainty and rationale in a new file bound to both primary hashes and the packet hash. Preserve unresolved alternatives as UNKNOWN; do not force agreement. Any clerical correction is a separately signed/hash-bound addendum, not an overwritten original.

The workflow pilot records whether readers can locate cases, use context, express uncertainty and preserve isolated custody. It cannot establish a full-score accuracy rate. No actual human observations are supplied by the preparation software.
